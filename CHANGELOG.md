# Changelog

## 0.4.1

First public release.

- Find the active order using a signed-in Uber Eats browser session.
- Expose status, restaurant, ETA bounds, order timing, courier location, and
  the latest observed outcome as Home Assistant entities.
- Show an intermediate stop count when Uber reports one.
- Include a dashboard card with live tracking, a conditional map, and manual
  refresh.
- Support installation through HACS or Home Assistant Marketplace.
